### Descrição do Projeto

O projeto iniciou na disciplina de Sistemas Multiagentes (SMA) ministrada pela prof. Drª. Célia G. Ralha,
com o grupo sendo formado pelos alunos Lucas Stadler Karau, Marcos Vinicius Santos Passos e Victor Novoli Mendonça.

O objetivo principal deste trabalho é integrar hardware (Arduino) com o framework MASPY (Multi-agent System for Python),
visando facilitar o entendimento e estudo de como agentes inteligentes funcionam, se comunicam, interagem com o ambiente
e como aprendem com as informações que obtém. 

---

### Tecnologias Utilizadas
MASPY (versão), Arduino (versão), Javino (versão)
